# Photo Booth สำหรับคอมพิวเตอร์ (Windows / Mac) — ต่อกล้องดิจิตอลได้

หน้าจอ ขั้นตอนถ่ายรูป กรอบ โทนสี อัปโหลด Google Drive และ QR อัลบั้ม **เหมือนเวอร์ชันมือถือทุกอย่าง** (ใช้โค้ดหน้าจอชุดเดียวกัน และใช้ `Code.gs` ตัวเดิม) ส่วนที่เพิ่มสำหรับคอมพิวเตอร์:

- เลือกกล้องได้หลายตัว (เว็บแคม, การ์ดแคปเจอร์ HDMI, กล้อง DSLR/Mirrorless ที่ทำงานเป็นเว็บแคม) และสลับกล้องระหว่างงานได้
- **สั่งกล้อง DSLR/Mirrorless ถ่ายรูปจริงเต็มความละเอียดผ่านสาย USB** แล้วนำรูปเข้ากรอบอัตโนมัติ (ถ้าสั่งไม่สำเร็จจะใช้ภาพจากพรีวิวแทน คิวแขกไม่ค้าง)
- **พิมพ์เงียบ** ไม่ต้องกดยืนยัน เลือกเครื่องพิมพ์ / ขนาดกระดาษ 4×6 / จำนวนชุด และพิมพ์อัตโนมัติทันทีหลังถ่ายได้
- เก็บสำเนารูปในโฟลเดอร์ที่เลือก, โหมดเต็มจอ/Kiosk, ปุ่มลัดคีย์บอร์ด (ใช้กับรีโมตพรีเซนต์/แป้นเหยียบได้)

> **สำคัญ:** โปรแกรมนี้ผมทดสอบด้วยกล้องและเครื่องพิมพ์จำลอง (โปรแกรมปลอมที่ทำตัวเหมือน digiCamControl/gPhoto2, Chromium พร้อมกล้องจำลอง) ยังไม่ได้ทดสอบกับกล้อง/เครื่องพิมพ์ยี่ห้อจริง ให้ใช้ปุ่ม **“ทดสอบสั่งกล้องถ่าย 1 ภาพ”** และ **“พิมพ์หน้าทดสอบ”** ในหน้าตั้งค่า ตรวจให้ผ่านก่อนวันงานจริงเสมอ

## 1) ได้โปรแกรมมาได้ 2 ทาง

### ทาง A — ให้ GitHub สร้างตัวติดตั้งให้ (ไม่ต้องลงอะไรในเครื่อง)

1. อัปโหลดทั้งโปรเจกต์ (มีโฟลเดอร์ `app` และ `desktop` อยู่ด้วยกัน) ขึ้น GitHub
2. แท็บ **Actions → Build Desktop → Run workflow** รอประมาณ 5–10 นาที
3. ท้ายหน้าการรัน หัวข้อ **Artifacts** ดาวน์โหลด
   - `PhotoBooth-Windows` → ไฟล์ติดตั้ง **`.msi`** (และ `.exe` ตัวติดตั้ง / แบบพกพา)
   - `PhotoBooth-Mac` → ไฟล์ติดตั้ง **`.dmg`** (แยก Intel `x64` และ Apple Silicon `arm64` — เครื่อง Mac ที่ใช้ชิป M1/M2/M3/M4 เลือกไฟล์ `arm64`)

> ไฟล์ `.msi` ต้องสร้างบน Windows และ `.dmg` ต้องสร้างบน Mac เท่านั้น จึงต้องผ่าน GitHub Actions (เครื่องของ GitHub เป็น Windows/Mac จริง) หรือสร้างบนเครื่องนั้นเอง ไม่สามารถสร้างจากเครื่องอื่นได้

### ทาง B — สร้างบนเครื่องตัวเอง

1. ติดตั้ง [Node.js (เวอร์ชัน LTS)](https://nodejs.org/)
2. เปิด Terminal / Command Prompt ในโฟลเดอร์ `desktop` แล้วสั่ง

```
npm install
npm start            ← เปิดโปรแกรมทดลองใช้
npm run dist:win     ← สร้าง .msi + .exe สำหรับ Windows (ได้ไฟล์ใน desktop/dist)
npm run dist:mac     ← สร้าง .dmg สำหรับ Mac (ต้องรันบนเครื่อง Mac)
```

ถ้าแยกโฟลเดอร์ `desktop` ออกมาใช้เดี่ยวๆ ให้เก็บโฟลเดอร์ `www` ที่อยู่ข้างในไว้ด้วย (ถ้าอยู่ข้างโฟลเดอร์ `app` โปรแกรมจะคัดลอกหน้าจอล่าสุดมาให้เองทุกครั้งที่ `npm start`)

**ติดตั้ง:** Windows ดับเบิลคลิก `.msi` แล้วกด Next ตามขั้นตอน (หรือติดตั้งหลายเครื่องด้วยคำสั่ง `msiexec /i "Photo Booth 1.0.0.msi" /qn`) · Mac เปิด `.dmg` แล้วลากไอคอน Photo Booth ไปที่โฟลเดอร์ Applications

**ครั้งแรกที่เปิด:** Windows อาจขึ้น SmartScreen → กด *More info → Run anyway* · Mac ให้คลิกขวาที่โปรแกรม → *Open* (ตัวติดตั้งนี้ไม่ได้ลงลายเซ็นของ Apple/Microsoft) · ถ้า Mac ขึ้นว่า “ไฟล์เสียหาย/ตรวจสอบไม่ได้” ให้เปิด Terminal แล้วสั่ง `xattr -cr "/Applications/Photo Booth.app"` จากนั้นเปิดใหม่ แล้วอนุญาตให้ใช้กล้อง

## 2) ตั้งค่าครั้งแรก

เปิดโปรแกรม → กด **Ctrl+,** (Mac: ⌘+,) หรือคลิกไอคอน ⚙ จางๆ มุมขวาบนของหน้าแรก

1. ใส่ชื่ออีเวนต์, Apps Script URL และ Token, กด “ทดสอบการเชื่อมต่อ”, สร้าง QR อัลบั้ม — **ขั้นตอนเหมือนเวอร์ชันมือถือทุกอย่าง** (ดู `README-TH.md` ขั้นที่ 1)
2. **กล้อง / การ์ดแคปเจอร์ที่ใช้ดูภาพสด:** เลือกกล้องจากรายการ ถ้าไม่เห็นให้กด “ค้นหากล้องใหม่”
3. ตั้งค่ากล้องดิจิตอลและเครื่องพิมพ์ตามหัวข้อด้านล่าง

## 3) ต่อกล้อง — เลือกให้ตรงกับอุปกรณ์ที่มี

| อุปกรณ์ | วิธีต่อ | คุณภาพรูป | ตั้งค่าในโปรแกรม |
|---|---|---|---|
| เว็บแคม / กล้อง USB (UVC) | เสียบแล้วเลือกในรายการกล้อง | ตามเว็บแคม (ส่วนใหญ่ 1080p) | “วิธีถ่ายรูปจริง” = ปิด |
| กล้อง DSLR/Mirrorless ในโหมดเว็บแคม | ติดตั้งโปรแกรมเว็บแคมของยี่ห้อ เช่น Canon *EOS Webcam Utility*, Sony *Imaging Edge Webcam*, Nikon *Webcam Utility*, Fujifilm *X Webcam*, Panasonic *LUMIX Webcam* แล้วเลือกเป็นกล้อง | 1080p (ภาพจากพรีวิว) | “วิธีถ่ายรูปจริง” = ปิด |
| กล้อง DSLR/Mirrorless + **การ์ดแคปเจอร์ HDMI** | สาย HDMI จากกล้อง → การ์ดแคปเจอร์ (ภาพสด) | 1080p (ภาพจากพรีวิว) | “วิธีถ่ายรูปจริง” = ปิด |
| **ภาพสดจากการ์ดแคปเจอร์ + สั่งชัตเตอร์ผ่าน USB** (แนะนำสำหรับงานจริง) | HDMI → การ์ดแคปเจอร์ และสาย USB จากกล้องเข้าคอม | **เต็มความละเอียดกล้อง** | “วิธีถ่ายรูปจริง” = สั่งถ่ายผ่านโปรแกรมควบคุมกล้อง หรือ รอรูปใหม่จากโฟลเดอร์ |

กล้องส่วนใหญ่ใช้ USB เป็น “เว็บแคม” กับ “สั่งชัตเตอร์” **พร้อมกันไม่ได้** จึงแนะนำให้ภาพสดมาจาก HDMI และสั่งถ่ายผ่าน USB (หรือเลือกใช้ภาพจากเว็บแคมอย่างเดียว คุณภาพจะเท่า 1080p)

### วิธีที่ 1: สั่งถ่ายผ่านโปรแกรมควบคุมกล้อง (โหมด “command”)

โปรแกรมจะรันคำสั่งที่คุณกำหนด ให้โปรแกรมควบคุมกล้องถ่ายรูปแล้วบันทึกเป็นไฟล์ที่ `{out}` จากนั้นนำรูปมาใส่กรอบ

**Windows — digiCamControl** (ฟรี รองรับ Canon/Nikon/Sony หลายรุ่น)
1. ติดตั้ง [digiCamControl](https://digicamcontrol.com/) ต่อกล้องทาง USB ตั้งกล้องให้บันทึก **JPEG** (ไม่ใช่ RAW อย่างเดียว) แล้วลองถ่ายในโปรแกรมของเขาให้ผ่านก่อน
2. ในหน้าตั้งค่า เลือก “ชุดคำสั่งสำเร็จรูป” = *digiCamControl (Windows)* จะได้
   `"C:\Program Files (x86)\digiCamControl\CameraControlCmd.exe" /filename "{out}" /capture`
   (ถ้าติดตั้งไว้ที่อื่นให้แก้ path)
3. กด “ทดสอบสั่งกล้องถ่าย 1 ภาพ” ต้องขึ้นขนาดรูปและเห็นภาพตัวอย่าง ถ้าไม่ผ่านให้ลองปิดหรือเปิดหน้าต่างหลักของ digiCamControl แล้วทดสอบใหม่ (ชื่อพารามิเตอร์อาจต่างกันเล็กน้อยตามเวอร์ชัน ดูคู่มือ *Command line utilities* ของโปรแกรม)

**Mac / Linux — gPhoto2**
1. Mac: ติดตั้ง [Homebrew](https://brew.sh/) แล้วสั่ง `brew install gphoto2` · เช็กว่ากล้องรุ่นนั้นรองรับที่ <http://gphoto.org/proj/libgphoto2/support.php> (Sony ให้ตั้งโหมด USB เป็น *PC Remote*)
2. เลือก “ชุดคำสั่งสำเร็จรูป” = *gPhoto2* จะได้
   `gphoto2 --capture-image-and-download --force-overwrite --filename "{out}"`
3. โปรแกรมปิดตัวแย่งกล้องของ macOS (`PTPCamera`) ให้อัตโนมัติก่อนถ่ายทุกครั้ง · กด “ทดสอบสั่งกล้องถ่าย”

**โปรแกรมอื่นก็ใช้ได้** ขอแค่มีคำสั่งแบบบรรทัดคำสั่งที่เซฟรูปลงไฟล์ตามชื่อที่กำหนด ใส่ `{out}` ตรงตำแหน่งชื่อไฟล์ และใส่ path ที่มีช่องว่างไว้ในเครื่องหมาย `" "` (ไม่ใช้ shell จึงไม่ต้องกังวลเรื่อง quote พิเศษ; ไฟล์ `.bat` ใช้ตรงๆ ไม่ได้ ให้ใช้ `.exe`)

### วิธีที่ 2: รอรูปใหม่จากโฟลเดอร์ (โหมด “folder / Hot folder”)

เหมาะกับโปรแกรมของยี่ห้อกล้องที่ดึงรูปลงโฟลเดอร์ให้เอง เช่น Canon *EOS Utility*, Sony *Imaging Edge Desktop (Remote)*, Nikon *Camera Control Pro / NX Tether*, Lightroom Classic (Tethered Capture) แล้วโปรแกรมนี้จะหยิบ **ไฟล์ใหม่ล่าสุดที่เพิ่งเข้ามาหลังกดถ่าย** ไปใส่กรอบ (ไฟล์ต้นฉบับยังอยู่ในโฟลเดอร์ ไม่ถูกลบ)
- เลือก “โฟลเดอร์ที่โปรแกรมกล้องบันทึกรูปลงมา” และตั้งกล้อง/โปรแกรมให้บันทึก JPEG
- ถ้ามีคำสั่งสั่งชัตเตอร์ (เช่น digiCamControl `CameraControlCmd.exe /capture` ที่ตั้งให้ลงโฟลเดอร์นั้น) ใส่ไว้ในช่อง “คำสั่งถ่ายรูป” โปรแกรมจะสั่งแล้วรอรูปให้ · ถ้าเว้นว่าง จะรออย่างเดียว ต้องมีคนกดชัตเตอร์ที่กล้อง/รีโมตเอง

### ข้อควรรู้เมื่อถ่ายผ่านกล้องดิจิตอล
- ใช้เวลาประมาณ 1–4 วินาทีหลังกดถ่าย ระหว่างนั้นหน้าจอจะขึ้นไอคอน 📸
- มุมภาพของรูปจริงอาจต่างจากภาพสดเล็กน้อย (เช่น กล้องสัดส่วน 3:2 แต่ภาพสดผ่าน HDMI เป็น 16:9) เพราะทั้งคู่ถูกครอปกึ่งกลางให้เท่าสัดส่วนที่เลือก ลองถ่ายทดสอบแล้วปรับการวางกล้อง
- ต้องเป็นไฟล์ JPEG หรือ PNG ถ้ากล้องบันทึก RAW อย่างเดียว โปรแกรมจะแจ้งให้ตั้งเป็น JPEG
- ถ้าสั่งกล้องไม่สำเร็จ (กล้องดับ สายหลุด) โปรแกรมจะขึ้นข้อความสั้นๆ และใช้ภาพจากพรีวิวถ่ายแทน เพื่อให้แขกได้รูปเสมอ

## 4) การพิมพ์

1. ติดตั้งไดรเวอร์เครื่องพิมพ์ (เช่น DNP DS620/QW410, Canon Selphy, HiTi, Mitsubishi, Epson) และตั้งกระดาษเริ่มต้นในไดรเวอร์เป็น 4×6 ให้ถูกก่อน
2. ในโปรแกรม: “วิธีพิมพ์” = **พิมพ์เงียบ**, เลือกเครื่องพิมพ์, “ขนาดกระดาษ” = 4×6 นิ้ว, ตั้งจำนวนชุด
3. กด **พิมพ์หน้าทดสอบ** ดูว่าภาพเต็มกระดาษ ไม่เอียง ไม่มีขอบขาว
4. เปิด “พิมพ์อัตโนมัติทันทีหลังถ่าย” ถ้าอยากให้ออกเครื่องพิมพ์เลย (หน้าผลลัพธ์ยังกด “พิมพ์” เพิ่มได้)

ถ้าขนาดกระดาษไม่ตรง (บางไดรเวอร์ตั้งชื่อกระดาษเฉพาะ) ให้เลือก “ตามที่ตั้งไว้ในไดรเวอร์เครื่องพิมพ์” แล้วไปตั้งขนาดในไดรเวอร์แทน · ใบ QR อัลบั้มพิมพ์ด้วยวิธีเดียวกัน

## 6) ใช้งานจริงในงาน

- เปิดแบบเต็มจอล็อก: `npm run kiosk` หรือเปิดโปรแกรมด้วยอาร์กิวเมนต์ `--kiosk` (สร้างทางลัดแล้วต่อท้าย `--kiosk` ที่ช่อง Target) หรือติ๊ก “เปิดโปรแกรมแล้วเต็มจอทุกครั้ง” ในตั้งค่า
- ออกจากโปรแกรม: Ctrl+, → เลื่อนลงล่างสุด → “ปิดโปรแกรม” (หรือ Alt+F4 / ⌘+Q)
- ให้เปิดเองตอนเปิดเครื่อง (Windows): กด Win+R พิมพ์ `shell:startup` แล้ววางทางลัดของโปรแกรมไว้ในโฟลเดอร์นั้น
- โปรแกรมกันหน้าจอดับให้เองขณะเปิดอยู่
- รูปที่ถ่ายเก็บไว้ที่ `รูปภาพ/PhotoBooth/<ชื่ออีเวนต์>/` (เปลี่ยนได้ในตั้งค่า) และอัปโหลดขึ้น Google Drive พร้อมคิวส่งซ้ำเมื่อเน็ตหลุด เหมือนเวอร์ชันมือถือ
- ความเป็นส่วนตัวของ QR อัลบั้ม: เหมือนเวอร์ชันมือถือ (QR พาไปอัลบั้มรวมของงาน ใครสแกนเห็นทุกรูป)

## 8) โครงสร้างไฟล์

```
desktop/
  src/main.js        เปิดหน้าต่าง · โหลดหน้าจอผ่าน app:// พร้อม CSP · อนุญาตเฉพาะกล้อง
  src/preload.js     สะพานแคบๆ ไปยังโปรเซสหลัก (หน้าจอไม่มีสิทธิ์ Node)
  src/handlers.js    ช่อง IPC: อัปโหลด (เฉพาะ script.google.com) · เก็บรูป · เลือกโฟลเดอร์ · เต็มจอ
  src/capture.js     สั่งกล้องดิจิตอล (command / folder)
  src/printing.js    พิมพ์เงียบ
  scripts/sync-www.js คัดลอกหน้าจอจาก ../app/src/main/assets/www
  tests/             unit test (npm test)
```

หน้าจอทั้งหมดอยู่ที่ `app/src/main/assets/www/` ชุดเดียว แก้ที่นั่นแล้วมีผลทั้ง Android และคอมพิวเตอร์
