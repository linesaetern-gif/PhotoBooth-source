# Photo Booth (แอป Android)

> 💻 **เวอร์ชันคอมพิวเตอร์ (Windows/Mac) ที่ต่อกล้อง DSLR/Mirrorless ได้** อยู่ในโฟลเดอร์ `desktop/` — อ่านวิธีใช้ที่ [`desktop/README-TH.md`](desktop/README-TH.md) (ใช้ `Code.gs` และการตั้งค่า Google Drive ชุดเดียวกัน)

แอปสำหรับงานอีเวนต์: เปิดกล้อง → เลือกกรอบ/โทนสี/สัดส่วน/ขนาด → กดถ่าย (นับถอยหลัง) → พิมพ์ → รูปอัปโหลดขึ้น Google Drive อัตโนมัติ
แขกสแกน **QR Code ใบเดียวที่พิมพ์ติดหน้าบูธ** เพื่อเปิดอัลบั้มรูปของงานใน Drive

## วิธีใช้งานในแอป

1. **หน้าแรก** แตะปุ่มใหญ่เพื่อเริ่ม (แตะ ⚙ มุมขวาบนเพื่อเข้าตั้งค่า)
2. **หน้ากล้อง** เห็นภาพสดพร้อมกรอบ ยังไม่นับถอยหลังจนกว่าจะกดปุ่ม **ถ่ายรูป** ด้านล่าง ปรับได้จากแถบเครื่องมือก่อนกด:
   - 🖼 กรอบ (มีตัวอย่างให้ดู) · 🧩 คอลลาจ (ภาพเดียว / 2 / 3 / 3 แบบใหญ่+เล็ก / 4 ตาราง / 4 แนวยาว — สูงสุด 4 ภาพ) · 🎨 โทนสี (17 โทน) · 📐 สัดส่วน/แนว (2:3, 3:4, 1:1, 9:16, ตามกล้อง) · 📏 ขนาด (เล็ก/มาตรฐาน/ใหญ่) · ⏱ นับถอยหลัง (ไม่นับ/3/5/10 วิ) · 🔍 ซูม/มุมมอง
   - **แนวตั้ง/แนวนอน** สลับได้ที่ปุ่มกลางด้านบน หรือในแผง 🖼 กรอบ และ 📐 สัดส่วน (ค่าเริ่มต้นคือแนวนอน)
   - **คอลลาจ**: กดถ่ายครั้งเดียว ระบบนับถอยหลังและถ่ายต่อเนื่องจนครบทุกช่อง ("ภาพที่ 2 / 4") แล้วรวมเป็นรูปเดียวใส่กรอบ อัปโหลด/พิมพ์เป็นรูปเดียว
   - กดปุ่มถ่ายซ้ำระหว่างนับถอยหลังเพื่อยกเลิก
3. **หน้าผลลัพธ์** พิมพ์ / ถ่ายใหม่ (กลับหน้ากล้องและรอกดปุ่มถ่าย) / เสร็จสิ้น รูปถูกส่งขึ้น Drive เบื้องหลัง (ไม่แสดง QR ตรงนี้)

ตัวเลือกที่เลือกไว้จะถูกจำไว้ จนกว่าจะเปลี่ยนใหม่

## ถ้าภาพในกล้องซูมใกล้เกินไป

- ถ้ามีข้อความบนภาพว่า “ภาพถูกตัด… แตะเพื่อเห็นภาพกล้องทั้งหมด” แตะที่ข้อความนั้น (หรือ 🔍 ซูม/มุมมอง → **เห็นภาพกล้องทั้งหมด**) ภาพกล้องจะแสดงเต็มเฟรมไม่ครอป โดยเติมขอบด้วยภาพเบลอ และรูปที่บันทึกจะเหมือนกับที่เห็น
- สาเหตุที่ภาพดูซูมใกล้: กรอบแนวตั้งต้องตัดภาพกล้องที่เป็นแนวนอนออกด้านข้าง การใช้ **แนวนอน** จะตัดน้อยลงมาก
- ตั้งค่า → **มุมมองกล้อง** เลือก **4:3 มุมกว้าง** (ค่าเริ่มต้นแล้ว) ซึ่งใช้พื้นที่เซนเซอร์เต็ม
- หน้ากล้อง → 📐 สัดส่วน → **ตามกล้อง (ไม่ครอป)** จะเห็นภาพเต็มโดยไม่ตัดขอบ
- หน้ากล้อง → 🔍 **ซูม** ลากแถบได้ ถ้ากล้องรุ่นนั้นรองรับซูมจริง (บางรุ่นซูมออกให้กว้างกว่า 1× ได้) แถบจะขยายช่วงให้เอง ถ้าไม่รองรับจะซูมเข้าด้วยการครอปภาพ (1×–3×)
- ในหน้าตั้งค่า/แผงซูมจะแสดง “กล้องส่งภาพขนาด W×H” ถ้ายังซูมใกล้ ส่งตัวเลขนี้มาให้ผมดูได้

## ขั้นที่ 1 — ตั้งค่า Google Drive (ทำครั้งเดียว)

1. เปิด <https://script.google.com> ด้วยบัญชี Google ที่จะเก็บรูป → **โครงการใหม่**
2. กด Ctrl+A ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดจากไฟล์ `apps-script/Code.gs` (เปิดไฟล์แล้วคัดลอกทั้งไฟล์)
3. แก้ `var TOKEN = 'change-me'` เป็นรหัสของคุณเอง (ตัวพิมพ์เล็กกับตัวเลขล้วน เช่น `booth2026`)
4. **Deploy → New deployment** → ประเภท **Web app** → Execute as: **Me** · Who has access: **Anyone** → Deploy → อนุญาตสิทธิ์ Drive → คัดลอก **Web app URL** (ลงท้าย `/exec`)

> **ถ้าเคย Deploy ไว้แล้ว** ต้องวาง `Code.gs` ใหม่เวอร์ชันนี้ แล้ว **Deploy → Manage deployments → ดินสอ → Version: New version → Deploy** (URL เดิมใช้ต่อได้ และต้องแก้ `TOKEN` อีกครั้ง) ไม่เช่นนั้นปุ่ม “สร้าง QR จาก Drive” จะบอกว่าสคริปต์เป็นเวอร์ชันเก่า

รูปจะอยู่ที่ `My Drive / PhotoBooth / <ชื่ออีเวนต์> /`

## ขั้นที่ 2 — สร้างไฟล์ APK

### วิธี A: Android Studio

1. แตกไฟล์ zip → เปิด Android Studio → **Open** โฟลเดอร์ `PhotoBooth` → รอ Gradle sync เสร็จ
2. เมนู **Build → Build Bundle(s) / APK(s) → Build APK(s)** (เวอร์ชันใหม่: **Build → Generate App Bundles or APKs → Generate APKs**) หรือแผง Gradle → app → Tasks → build → **assembleDebug**
   - ต้องเป็นคำสั่งสร้าง APK เท่านั้น **Make Project / Rebuild Project จะไม่สร้างไฟล์ APK**
3. ไฟล์อยู่ที่ `app/build/outputs/apk/debug/app-debug.apk` (กด **locate** ในแจ้งเตือนมุมขวาล่างได้)

### วิธี B: ให้ GitHub สร้างให้ (ไม่ต้องลงโปรแกรม)

1. สร้าง repository ใน <https://github.com> แล้วอัปโหลดไฟล์ทั้งโฟลเดอร์ **รวมโฟลเดอร์ `.github`** (ใช้ GitHub Desktop หรือคำสั่ง git ด้านล่าง)
   ```
   git init && git add . && git commit -m "Photo Booth"
   git branch -M main
   git remote add origin https://github.com/<ชื่อคุณ>/<ชื่อ repo>.git
   git push -u origin main
   ```
2. แท็บ **Actions → Build APK → Run workflow** รอ 3–6 นาที
3. เปิดการรันนั้น (หน้า Summary) เลื่อนลงล่างสุดหัวข้อ **Artifacts** → ดาวน์โหลด `PhotoBooth-debug-apk` → แตก zip ได้ `app-debug.apk`

### อัปเดตจากเวอร์ชันก่อนหน้า

เขียนทับไฟล์เหล่านี้ในโปรเจกต์เดิมแล้ว build ใหม่ (ค่าตั้งค่าในแอป เช่น URL/Token จะยังอยู่ถ้าติดตั้งทับ):
`app/src/main/assets/www/` (ทั้งโฟลเดอร์), `apps-script/Code.gs` (ต้องวางใน Google ใหม่ด้วย), `tests/`, `README-TH.md`

## ขั้นที่ 3 — ติดตั้งและตั้งค่าในแอป

1. ส่ง APK เข้าเครื่อง แตะติดตั้ง (อนุญาต “ติดตั้งแอปจากแหล่งที่ไม่รู้จัก”) ต้องใช้ Android 8.0 ขึ้นไป
2. เปิดแอป → อนุญาตกล้อง → แตะ **⚙** → ใส่ชื่ออีเวนต์, **Apps Script URL**, **Token** → กด **ทดสอบการเชื่อมต่อ** ต้องขึ้น “เชื่อมต่อสำเร็จ ✓”
3. เลื่อนลงที่ **QR Code อัลบั้มงาน** → กด **สร้าง QR จาก Drive** → ลองสแกนด้วยมือถือ → กด **🖨 พิมพ์ใบ QR** (หรือ 💾 บันทึกลงแกลเลอรีไว้ส่งไปพิมพ์ที่อื่น) แล้วนำไปติดหน้าบูธ
   - ใบ QR ขนาด 4×6 นิ้ว มีชื่องานและข้อความชวนสแกน
   - ใช้ QR เดิมได้ตลอดทั้งงาน ถ้าเปลี่ยน **ชื่ออีเวนต์** รูปใหม่จะไปอยู่โฟลเดอร์ใหม่ ต้องกดสร้าง QR ใหม่ (แอปจะเตือน)
   - ถ้าอยากให้ QR พาไปที่อื่น (เช่นโฟลเดอร์ Drive ที่คุณสร้างเอง) วางลิงก์ลงในช่อง “ลิงก์ที่ QR พาไป” ได้เลย
4. กลับหน้าแรก แตะเพื่อลองถ่าย

## ข้อควรรู้

- **ความเป็นส่วนตัว:** QR ใบเดียวพาไปที่อัลบั้มรวม ใครสแกนหรือมีลิงก์จะเห็น **รูปของแขกทุกคนในงานนั้น** ควรแจ้งแขกให้ทราบ และใช้ชื่ออีเวนต์ใหม่ทุกงาน ถ้าต้องการปิดอัลบั้มหลังงาน ให้ไปปิดการแชร์โฟลเดอร์ใน Google Drive
- บัญชี Google Workspace บางองค์กรปิดการแชร์ภายนอก ทำให้ QR เปิดไม่ได้ แนะนำบัญชี Gmail ปกติ
- **การพิมพ์** ใช้หน้าต่างพิมพ์มาตรฐานของ Android ต้องแตะยืนยันทุกครั้ง และต้องมีเครื่องพิมพ์ที่ Android มองเห็น (Wi‑Fi/Mopria/ปลั๊กอินยี่ห้อนั้น) การพิมพ์อัตโนมัติไม่ต้องกดต้องใช้ SDK ของเครื่องพิมพ์รุ่นนั้น
- ถ้าเน็ตหลุด รูปจะเก็บในคิวแล้วส่งซ้ำเอง (หน้าแรกจะแสดง “รออัปโหลด N รูป”) และไม่ทำให้รูปซ้ำใน Drive
- ⚙ ตั้งค่าเข้าได้ด้วยการแตะ แนะนำเปิด “ตรึงแอป (Screen pinning)” ของ Android เพื่อไม่ให้แขกออกจากแอป
- APK เป็นแบบ debug ติดตั้งเองได้ แต่ยังขึ้น Google Play ไม่ได้

## ก่อนวันงาน

- ลองครบวงจรบนเครื่องจริง: ถ่าย → พิมพ์ → ดูรูปขึ้น Drive → สแกน QR ด้วยมือถืออีกเครื่อง
- ต่อสายชาร์จตลอดงาน เตรียม Wi‑Fi/ฮอตสปอตสำรอง
- ถ้าแก้ `Code.gs` ต้อง Deploy เป็น New version ใหม่ทุกครั้ง

## แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
|---|---|
| กล้องไม่ขึ้น | ตั้งค่าเครื่อง → แอป → Photo Booth → สิทธิ์ → เปิดกล้อง แล้วกด “ลองอีกครั้ง” |
| ภาพซูมใกล้เกินไป | ดูหัวข้อ “ถ้าภาพในกล้องซูมใกล้เกินไป” ด้านบน |
| Apps Script ขึ้น SyntaxError ตอนบันทึก | Ctrl+A ลบโค้ดเดิมก่อนวาง เปิดไฟล์ `Code.gs` แล้วคัดลอกทั้งไฟล์ (ไม่ก๊อปจากช่องแชต) บรรทัดแรกต้องเป็น `// Photo Booth -> ...` |
| ทดสอบแล้วขึ้น “ตอบกลับไม่ถูกต้อง” | Deploy ต้องตั้ง Who has access = **Anyone** |
| “รหัสผ่าน (Token) ไม่ตรง” | ค่าใน `Code.gs` กับในแอปต้องตรงทุกตัวอักษร แล้ว Deploy เป็น New version |
| สร้าง QR แล้วขึ้น “สคริปต์ยังเป็นเวอร์ชันเก่า” | วาง `Code.gs` ใหม่ แล้ว Deploy เป็น New version |
| QR เปิดแล้วขอสิทธิ์เข้าถึง | บัญชี Workspace ปิดการแชร์ภายนอก ใช้ Gmail ปกติ |
| ปุ่มพิมพ์ไม่เห็นเครื่องพิมพ์ | ตั้งค่าเครื่อง → การพิมพ์ → เพิ่มเครื่องพิมพ์/เปิดบริการพิมพ์ของยี่ห้อนั้น |
| Build แล้วไม่มีไฟล์ APK | ต้องใช้คำสั่ง Build APK(s)/assembleDebug ไม่ใช่ Make Project (ดูขั้นที่ 2) |

## โครงสร้างไฟล์

```
app/src/main/assets/www/                หน้าเว็บของแอป (index.html, style.css, js/…)
app/src/main/java/…/MainActivity.java   WebView + กล้อง + พิมพ์ + ส่งข้อมูลขึ้น Drive
apps-script/Code.gs                     สคริปต์ฝั่ง Google Drive
.github/workflows/build-apk.yml         ให้ GitHub สร้าง APK
.github/workflows/build-desktop.yml     ให้ GitHub สร้างตัวติดตั้ง Windows/Mac
desktop/                                เวอร์ชันคอมพิวเตอร์ (Electron) ดู desktop/README-TH.md
tests/                                  unit test (รันด้วย: node --test)
```

ลองหน้าเว็บบนคอมได้ด้วย `python3 -m http.server 8080 -d app/src/main/assets/www` แล้วเปิด <http://localhost:8080> (ใช้เว็บแคมได้ ปุ่มพิมพ์จะใช้หน้าต่างพิมพ์ของเบราว์เซอร์)
